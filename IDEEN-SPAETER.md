## Shorts mit „Gesicht“ / Figur

- **Sprechende Organe** (Niere, Darm, Leber als Maskottchen, die einen Tipp in die
  Kamera sagen) — eigenes Unterformat auf TikTok/Shorts.
  [capturesai](https://capturesai.com/viral/viral-health-video),
  Beispielkanal: [AI Health and Entertainment](https://www.youtube.com/channel/UCiWpijV0pfh4PnMidzK7diw)
- **Sprechendes Obst/Essen** („Fruit Drama“, nummerierte Folgen 30–60 s) — Trend 2026,
  größtes Beispiel „Fruit Love Island“ (vor allem TikTok).
  [aituber.app](https://aituber.app/blog/talking-food-fruit-videos/),
  [Wikipedia](https://en.wikipedia.org/wiki/Fruit_Love_Island)
- **Echte Ärzte vor der Kamera** bauen Vertrauen auf (Google-Fallstudie zu einem
  Notarzt-Creator): [Case Study](https://services.google.com/fh/files/misc/final-en-yt-health-case-study-doktorweigl.pdf)
- Häufige Themen: Kreatin, Magnesium, Koffein; Hooks wie „Hör auf, X zu …“ /
  „Du brauchst X gar nicht“. [fluxnote](https://fluxnote.io/guides/health-youtube-shorts-ideas)
- **Warnung:** KI-Avatare mit Mega-Dosis-Empfehlungen (Magnesium) stehen in der Kritik —
  keine Dosierempfehlungen, nur belegte Fakten. [Decrypt](https://decrypt.co/331687/ai-avatars-pushing-mega-dose-magnesium-doctors-health-risk)

## Werkzeuge

- **Higgsfield** (Abo, Anfang Nov. 2026): Basic ~9 $/Monat (120 Credits),
  Pro ~29 $ (600 Credits ≈ 300 Nano-Banana-Pro-Bilder), Max ~79 $.
  Gleichbleibende Figur über „Soul ID“, Lippensynchron über „Lipsync Studio“.
  Credits verfallen monatlich, keine öffentliche API (nur MCP/CLI).
  Preise vor dem Kauf auf higgsfield.ai/pricing prüfen.
  [Scopeful](https://www.scopeful.org/tools/higgsfield),
  [AutoKeyWorder](https://autokeyworder.com/blog/higgsfield-pricing/),
  [aireiter](https://aireiter.com/blog/higgsfield-ai-reviews-pricing-vs-api)
- **Nano Banana Pro** (Google-Bildmodell): ~0,15 $/Bild in 2K über Higgsfield,
  direkt per API ~0,09 $ — Abo lohnt erst ab ~400 Bildern/Monat.
  [aivideobootcamp](https://aivideobootcamp.com/blog/nano-banana-pro-complete-guide-2026/)

## Möglicher Weg in diesem Projekt

Figur (z. B. ein Darm- oder Vitamin-Maskottchen) einmal mit Nano Banana Pro gestalten →
in Higgsfield als feste Figur anlegen → kurze Sprech-Clips erzeugen → in Remotion
als Einspieler zwischen die animierten Grafiken setzen. Remotion bleibt das Gerüst.

## Tempo-Recherche (umgesetzt in Version B)

- Erklär-Tempo ~125–145 Wörter/min; gezielte Pausen 0,3–0,5 s an Pointen,
  längere Pausen wirken wie Leerlauf. [BlitzCut](https://blitzcutai.com/blog/dead-air-kills-youtube-watch-time),
  [FluxNote](https://fluxnote.io/guides/faceless-shorts-retention-tips-2026)
- Hook in den ersten 1–3 s, auch als Text im Bild (viele schauen ohne Ton).
  [aivideosensei](https://aivideosensei.com/guides/youtube-shorts-with-ai)
- Bild alle ≤ 5 s verändern; Länge für Erklär-Shorts 45–60 s, länger nur bei guter Haltequote.
  [Opus](https://opus.pro/blog/ideal-youtube-shorts-length-format-retention)
